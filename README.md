# Сайт aksonmegavit.uz

Сайт каталога Akson Megavit на GitHub Pages. Публикуется через GitHub Actions
(`.github/workflows/pages.yml`) после каждого коммита в `main`.

- Товары: `products.json`, планируемые продукты: `planned.json`.
- Админка: `/admin/` — вход по личному токену GitHub владельца (Contents: Read and write).
  Админка загружает картинки, обновляет JSON и делает один коммит; сайт пересобирается за 2–3 минуты.
- Сборка (`npm run build` → папка `_site/`, скрипт `build/build.mjs`):
  - все страницы: главная, каталог, о компании, планируемые, 404 (`build/pages.mjs`)
    и страница каждого товара `/mahsulot/<slug>/` (`build/product-page.mjs`) на общем каркасе `build/layout.mjs`;
  - стили — один файл `site.css` (токены цветов, шрифт Manrope из `assets/fonts/`, тёмная тема);
  - каталог с готовым списком товаров (фильтр и поиск — `catalog.js`), `sitemap.xml`;
  - уменьшенные копии фото товаров (`-400.webp`, `-800.webp`) для каталога;
  - `version.json` с номером коммита — по нему админка понимает, что сайт обновился.
- Поля товара: `name`, `slug` (адрес страницы, латиницей), `category`, `brand`, `form`, `image`,
  `leaflets`, `description`, `composition`, `usage`; по желанию `name_lat` (своё написание латиницей)
  и `description_ru`, `composition_ru`, `usage_ru`. Необязательные поля можно не заполнять.
- Счётчики, категории и меню строятся при сборке из `products.json`.
- Контакты, адрес, карта, условия для партнёров и аналитика — в `site.json`
  (вкладка «Настройки сайта» в админке). Страницы «Алоқа» и «Ҳамкорлар учун» собираются из него.
- Языки (`build/i18n.mjs`): узбекский кириллицей — корень сайта, узбекский латиницей — `/uz/`, русский — `/ru/`
  (товары: `/ru/product/<slug>/`). Латиница получается транслитерацией автоматически. Тексты интерфейса
  пишутся парами (кириллица, русский). Описание, состав и применение из админки на русской версии пока не показываются.

Локально: `npm ci && npm run build`, затем открыть `_site/` любым статическим сервером.
